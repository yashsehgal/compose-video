# Demo video skills

Claude Code skills for making component breakdown videos with Remotion: a UI component walked from its old design to its new one, step by step, with hand-drawn notes, synthesized sound and a before/after close.

| Skill | Use it to |
|---|---|
| [component-demo-video](component-demo-video/SKILL.md) | Plan and build the video |
| [demo-video-sounds](demo-video-sounds/SKILL.md) | Add a version with sound |
| [review-demo-video](review-demo-video/SKILL.md) | Check a render before handing it over |

## Install

Copy the skill folders into `~/.claude/skills/`:

```bash
cp -R component-demo-video demo-video-sounds review-demo-video ~/.claude/skills/
```

The skills point to a local Remotion project (`/Users/yashsehgal/badge-video`) as their working example.
